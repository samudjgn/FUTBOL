# ⚽ Simulador de Tanda de Penaltis

Un motor de simulación de fútbol desarrollado en **Java**, enfocado en la resolución táctica de tandas de penaltis.

La arquitectura del código está construida sólidamente sobre los pilares de la **Programación Orientada a Objetos (POO)** (Herencia, Polimorfismo, Encapsulamiento). Para la gestión de datos en memoria, el sistema implementa estructuras de datos avanzadas como **HashMaps**, permitiendo un almacenamiento y búsqueda eficiente de la información de las plantillas de los equipos.

## 🚀 Cómo ejecutar el simulador

### Requisitos previos
* **Java Development Kit (JDK)** instalado en tu equipo.
* Un entorno de desarrollo (IDE) como IntelliJ IDEA, Eclipse o Apache NetBeans.
